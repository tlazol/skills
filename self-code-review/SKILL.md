# AI コードレビュー 5か条

- ユーザの指示した通りの実装になっているか自己レビューするべし。改善点あれば改善するべし。
- オーバーエンジニアリングするなかれ。プロジェクトの規模とコードのサイズのバランスを取るべし。
- 長期的な運用が可能なコードであるかの軸でもレビューしべし。
- オーバーエンジニアリングと、長期的な運用を見越した非結合化・細分化・ファイルやフォルダの分割のバランスを取るのが難しい場合は、ユーザに判断を尋ねるべし。
- 過剰にテストを量産するなかれ。書いて意味のあるテストコードのみを運用すべし。
